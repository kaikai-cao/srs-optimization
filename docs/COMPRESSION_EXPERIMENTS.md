# COMPRESSION_EXPERIMENTS — 奇偶幂次 / 前半部分 / 间隔采样恢复实验（M2-B）

> 状态：**完成**。实现 `crates/srs-relations/src/compression_tests.rs`；
> 原始数据 `results/raw/m2_results.json`，压缩参数样本 `results/raw/compression/*.bin`（均不入库）。
> 这一轮的结论是**负面结果**，且已定位到具体失败环节。

## 1. 实验契约

测试 SRS 与 M2-A 相同（`N=32`，Tau G1 序列长度 `2N-1=63`，固定种子）。
**压缩文件只保存 Tau G1 序列的一个子集**，格式：

```
magic "SCP1"(4) | sequence_len u32 | count u32 |
count x [ index u32 | 96 B arkworks uncompressed G1Affine ]
```

- 使用 arkworks canonical 序列化，**不是** `.ptau` 的 LEM/Montgomery 编码；
  这些文件是 M2 专用数学样本，不是 `.ptau` 片段。
- 其余四类公开参数（$Q_j, A_i, B_i, B_2$）视为各方案共有的辅助信息，
  在内存中提供但**不计入本表文件大小**，以便隔离 Tau G1 子序列的压缩效果。
  因此表中的百分比是「Tau G1 子序列」的节省，**不是整个 CRS 的压缩率**。
- 恢复接口：

```rust
fn recover_missing_powers(
    public_parameters: &CompressedParameters
) -> Result<Vec<G1Affine>, RecoveryError>
```

  `CompressedParameters` 只含压缩文件路径与公开辅助参数；
  **不含** $\tau,\alpha,\beta$，**不含**完整 Tau G1 数组。
  Rust 类型签名保证恢复代码拿不到秘密与原始数组；完整数组仅保留在
  `run_all` 中作为「逐点比较的 oracle」，不传入恢复函数。
  每个方案都经历：写文件 → `drop` 本地完整副本 → 仅凭 `pp` 恢复 → 逐点与原始点比较。

## 2. 实际尝试过的恢复手段（不是稻草人）

1. 压缩文件中已保存的点直接填入对应索引。
2. 用 M2-A 验证过的恒等式，把缺失 $P_k$ 的配对值转成可公开计算的 $G_T$ 目标：
   找保存的 $i$ 与合法 $j=k-i<N$，令 $t_k=e(P_i,Q_j)=e(P_k,Q_0)$。
3. 用群加法构造候选 $G_1$ 点：保存点本身、$2P_i$、$-P_i$、
   前 12 个保存点的两两和 $P_i+P_m$。
4. 用已知标量构造候选：$[c]G_1$，$c=1\ldots64$。
5. 把另外两类公开 $G_1$ 族 $A_i, B_i$ 及其倍点也加入候选集。
6. 用 $e(B_i,Q_0)=e(P_i,B_2)$ 在公开数据上做辅助一致性检查（用到 $B_2$）。
7. 对 $e(\cdot,Q_0):G_1\to G_T$ 做**有界求逆**：把全部候选点的 GT 像建表，
   查找与 $t_k$ 匹配的候选；命中后再用一次配对复核。
8. 阳性对照：把隐藏指数换成一个已知小整数 7，同一套有界求逆必须成功。

判定标准严格：**只有真正恢复出 $G_1$ 点并与原始点逐点相等才算成功**。
算出 $G_T$ 元素、或只通过配对一致性检查，一律记为失败。

## 4. 失败定位到哪一步

所有非基线方案都停在 **第 7 步：$G_T \to G_1$ 求逆**，返回：

```
pairing yields GT elements only; GT -> G1 inversion requires solving
the discrete log of tau^k, which is not a known public scalar
```

原因是结构性的：

- $e(\cdot,Q_0):G_1\to G_T$ 在非退化配对下是单射，且 $|G_1|=|G_T|=r$，
  因此 $t_k$ 在 $G_1$ 中**存在唯一**原像 $P_k=[\tau^k]G_1$；「不存在」不是问题，「构造不出来」才是问题。
- 要由 $t_k=e(G_1,G_2)^{\tau^k}$ 反推出点，等价于求 $\tau^k$ 关于底 $e(G_1,G_2)$ 的离散对数
  （$G_T$ 中约 255-bit 的 DLP），或等价地在 $G_1$ 中求 $\tau^k$。
  $\tau$ 是未知陷门，$\tau^k$ 不是任何已知小标量。
- 群律只允许对已知指数做**整数线性组合**：由 $\{\tau^{i}:i\in S\}$ 只能得到
  $\sum_i c_i\tau^{i}$（$c_i\in\mathbb Z$）。对随机 $\tau$，低次幂在 $\mathbb F_r$ 上
  不存在可用的小系数线性关系，因此 $\tau^k$ 落不在这个整数张成空间里。
  第 3–5 步的候选集正是这个空间的**有界**枚举，全部未命中。
- 另外两类公开参数族 $A_i=\alpha\tau^i G_1$、$B_i=\beta\tau^i G_1$ 引入的是
  $\alpha,\beta$ 因子，也不能凭空产生 $\tau^k G_1$。

**公开信息实际能做到的程度**：

- 能**验证**任意候选点：$e(X,Q_0)\stackrel{?}{=}t_k$（第 7 步的复核就是这个）。
- 能**算出** $G_T$ 目标 $t_k$，但只在可分解 $k=i+j$（$i$ 已保存、$j<N$）时才行。
  表中「可算 GT 目标」列显示这也不是全覆盖：
  仅奇数次幂 31/32（$k=0$ 无法分解）、前半部分 31/47（$k>46$ 超出 $j<N$）。
- **不能构造**缺失的 $G_1$ 点。$G_T$ 元素与 $G_1$ 点是两种不同对象，不能混为一谈。

## 5. 结论边界（必须明确）

- 对导师的两个设想，本轮给出的答案是：
  **在「不持有 $\tau,\alpha,\beta$、只依赖公开压缩文件」的前提下，
  奇偶次幂、前半部分、间隔采样都无法恢复出缺失的 $G_1$ 群元素。**
  递推式 $P_{i+1}=[\tau]P_i$ 成立，但 $[\tau]$ 本身不可公开计算，这正是断点。
- 这些存储减少百分比只是「少存了多少点」，**不构成可用的存储压缩**：
  点少了但恢复不出来，下游 Setup/Prove 无法使用。
- 本结论只否定了**本轮实际实现的恢复方法**（整数线性组合、已知标量、
  配对 GT 目标、有界求逆）。**不宣称从数学上证明了所有代数压缩都不可能**；
  例如改变参数表示、改变承诺方案或直接支持 MSM 而不恢复原点，都不在本轮否定范围内。
- 本轮没有设计新算法，也没有做流式 MSM / Power 21；下一阶段方向待统一汇报后再定。
